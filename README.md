Главная задача этого проекта написать самостоятельную модель которая сможет понять на сколько изношен авиационный двигатель и сколько циклов осталось до отказа 




Актуальная информация будет храниться в ветке developed, а в ветке main будет храниться последняя протестированная и рабочая версия модели
